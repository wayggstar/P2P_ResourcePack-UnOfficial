# P2P_ResourcePack

Instant P2P의 **방 만들기 / 방 설정 변경 → 리소스팩 설정**에서 서버 리소스팩을 지정하는 비공식 Fabric 애드온입니다.

## 설치

- Minecraft **26.3**, Java **25 이상**
- Fabric Loader **0.19.5 이상**, Fabric API **0.160.5+26.3**
- **Instant P2P 1.2.3 (26.3용)**
- 방장의 `mods` 폴더에 `P2P_ResourcePack-26.3-0.2.0.jar`를 추가합니다.
- 참가자는 Instant P2P로 접속하며, 이 애드온은 추가 설치할 필요가 없습니다. 기본 Minecraft 서버 리소스팩 패킷을 사용합니다.

## 사용 방법

1. 싱글플레이에서 Instant P2P의 **커스텀 방 만들기**를 엽니다.
2. **리소스팩 설정**을 누릅니다.
3. **ZIP 업로드… → ZIP 파일 선택**으로 팩을 고르거나 업로드 화면에 ZIP을 끌어놓습니다.
4. 로컬 검사 완료 후 **mcpacks.dev에 공개 업로드**를 누릅니다. 업로드와 재다운로드의 SHA-1이 일치하면 다운로드 URL과 해시가 자동 등록되고 서버 리소스팩 사용이 켜집니다.
5. 원하면 **필수 적용**을 켠 뒤 **저장**합니다. 방 설정으로 돌아와 방을 시작합니다.

기존처럼 HTTP(S) URL을 직접 입력하고 **팩 확인 · SHA-1 계산**을 눌러도 됩니다.

이미 열린 방에서는 저장 후 다음 서버 틱에 현재 접속자에게도 반영됩니다. 끄면 이 애드온이 보낸 팩만 제거합니다. 다른 모드가 보낸 팩은 제거하지 않습니다. 취소/ESC는 미저장 변경을 버립니다. 리소스팩 화면에 다녀와도 입력 중이던 방 제목은 유지됩니다.

설정은 `config/p2p_resourcepack.json`에 저장되며 **모든 월드에서 다음 방에도 공유**됩니다. 같은 URL의 ZIP을 수정했으면 **팩 확인**을 다시 눌러 새 해시를 저장하세요.

## 동작 범위

이 애드온은 ZIP **100 MiB 이하**로 제한하며, 다운로드 제한 시간·리다이렉트 횟수·메타데이터 크기 제한을 둡니다. 팩 확인은 다운로드 및 기본 구조 확인이며 모든 텍스처/셰이더의 호환성을 보증하지 않습니다.

## 빌드

Java 25를 설치하고, 원본 JAR을 `libs/instant-p2p-26.3-1.2.3.jar`에 넣습니다.

```sh
./gradlew build
```

산출물: `build/libs/P2P_ResourcePack-26.3-0.2.0.jar`

자동 테스트는 로컬 HTTP 서버로 다운로드·리다이렉트·잘못된 ZIP·크기 제한·설정 저장을 확인합니다. 실제 P2P 환경의 두 컴퓨터 간 접속/적용은 별도의 플레이 테스트가 필요합니다.

개발용 화면 검증: `./gradlew runClient -PsmokeTest`. 기존 월드를 열지 않고 방 설정 버튼, 리소스팩 화면 전환, 방 제목 보존 및 믹스인 로딩을 확인합니다. 이 검증용 모드는 배포 JAR에 포함되지 않습니다.

## mcpacks.dev 업로드

- 대상은 **mcpacks.dev (Obsidian Servers)**입니다. 이름이 비슷한 mc-packs.net과는 다른 서비스입니다.
- [공식 API 문서](https://mcpacks.dev/docs/api)에 따라 multipart `file` 필드와 선택적 `management_password`를 사용합니다. API 키는 필요 없습니다.
- 파일 선택/끌어놓기는 로컬 검사만 합니다. **공개 업로드 버튼을 눌렀을 때만** 외부로 전송합니다.
- 검증한 파일의 임시 사본을 업로드하며, 이후 반환된 URL에서 다시 받은 파일의 해시까지 확인합니다. 선택 이후 원본이 바뀌면 다시 선택해야 합니다.
- 업로드 성공 후에도 **저장**을 눌러야 방 설정이 바뀝니다. 저장 취소나 모드 설정 해제로 이미 업로드된 파일이 삭제되지는 않습니다.
- 파일은 외부 서비스의 공개 다운로드 주소에 올라가며 보관/만료 정책은 해당 서비스에 따릅니다. 영구 보관을 보장하지 않습니다.
- 관리 비밀번호와 서비스 응답(`manage_url` 포함)은 `config/p2p_resourcepack_uploads/upload-*.json`에 저장합니다. 관리/삭제가 필요하면 이 파일의 정보를 사용하세요. 이 파일은 다른 사람에게 공유하지 마세요. POSIX 시스템에서는 소유자만 읽고 쓸 수 있도록 저장합니다.
- API 실패 시 자동으로 재업로드하지 않습니다. 응답을 받기 전에 연결이 끊어졌다면 서버에는 파일이 올라갔을 수 있으므로 로컬 기록을 먼저 확인하세요.
- 파일 선택 창은 Minecraft 26.3에 포함된 SDL을 사용합니다. 선택 창이 지원되지 않는 환경에서는 ZIP 끌어놓기를 사용할 수 있습니다.

실제 공개 API 테스트는 기본 빌드에서 실행하지 않습니다. `./gradlew test -PliveUpload --tests dev.p2p.resourcepack.McPacksLiveTest`는 사용자 팩 대신 직접 생성한 메타데이터 전용 ZIP 하나를 mcpacks.dev에 공개 업로드합니다.
